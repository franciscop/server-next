# FAQ

### How is it different from Hono?

Server.js attempts to run your code unmodified in all runtimes. With Hono you need to change the code for different runtimes:

```js
// Server.js code for Node.js, Bun and Netlify
import server from "@server/next";
export default server().get("/", () => "Hello server!");
```

```js
// Hono code for Node.js
import { serve } from "@hono/node-server"
import { Hono } from "hono"
const app = new Hono()
app.get('/', (c) => c.text('Hello Node.js!'))
serve(app)

// Hono code for Bun
import { Hono } from "hono"
const app = new Hono()
app.get('/', (c) => c.text('Hello Bun!'))
export default app

// Hono code for Netlify
import { Hono } from "jsr:@hono/hono"
import { handle } from "jsr:@hono/hono/netlify"
const app = new Hono()
app.get('/', (c) => c.text('Hello Hono!'))
export default handle(app)
```

### How do I render HTML templates?

Server.js has no built-in template engine; return the rendered string from your route. One that starts with a tag is served as `text/html`, and [`type('html')`](/documentation/reply#type) covers anything that doesn't. See [Templates](/documentation#templates) for EJS, Pug and Handlebars examples, or [JSX](/documentation#jsx) on Bun.
