# Revocable sessions in Postgres

With a user id in the cookie, signing out only clears that browser: a copy taken beforehand keeps working. Point the cookie at a **session row** instead, and logout becomes real.

## 1. A row per login

```sql
CREATE TABLE sessions (
  id UUID PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  user_agent TEXT,
  ip TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 2. Point the credential at it

`onLogin` returns the **session** id rather than the user id, and `getUser` joins back:

```js
import postgres from 'postgres';
const sql = postgres(process.env.DATABASE_URL);

const auth = {
  providers: 'github',

  onLogin: async (profile, ctx) => {
    const [user] = await sql`
      insert into users (email, name, avatar)
      values (${profile.email}, ${profile.name}, ${profile.avatar})
      on conflict (email) do update set name = excluded.name
      returning id`;

    const [session] = await sql`
      insert into sessions (id, user_id, user_agent, ip)
      values (${crypto.randomUUID()}, ${user.id}, ${ctx.headers['user-agent'] ?? ''}, ${ctx.ip})
      returning id`;

    return session.id;
  },

  getUser: async (id) => (await sql`
    select users.* from sessions
    join users on users.id = sessions.user_id
    where sessions.id = ${id}`)[0],

  onLogout: (id) => sql`delete from sessions where id = ${id}`,
};
```

Same two callbacks as before, pointed at a different table. `onLogout` is the difference: `POST /auth/logout` now deletes the row, so that credential is dead everywhere rather than just in the browser that asked.

One join per request, which is the price of being able to revoke.

## 3. Their devices, in account settings

```js
  .get('/account/sessions', async (ctx) => {
    if (!ctx.user) return 401;
    return sql`
      select id, user_agent, ip, created_at from sessions
      where user_id = ${ctx.user.id} order by created_at desc`;
  })

  .del('/account/sessions/:id', async (ctx) => {
    if (!ctx.user) return 401;
    // Scoped by user_id, so nobody can end someone else's session
    await sql`
      delete from sessions
      where id = ${ctx.url.params.id} and user_id = ${ctx.user.id}`;
    return 204;
  })
```

Mark the current one with [`ctx.auth`](/documentation/context#ctxauth), which knows when this credential was issued.

## 4. Sign out everywhere

```js
  .post('/account/sign-out-everywhere', async (ctx) => {
    if (!ctx.user) return 401;
    await sql`delete from sessions where user_id = ${ctx.user.id}`;
    return 204;
  })
```

Worth doing on a password or email change, where ending a stolen session is the whole point.

## 5. Clean up

Rows outlive the cookies that point at them, so delete the stale ones on a schedule:

```sql
DELETE FROM sessions WHERE created_at < now() - interval '30 days';
```

The credential expires after [`expires`](/documentation/authentication#expires) (30 days by default) regardless, so anything older can never be presented.
