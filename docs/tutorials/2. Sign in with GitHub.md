# Sign in with GitHub

Add "Sign in with GitHub" to an app: log users in, protect a route, and let them log out. The same steps work for any OAuth provider.

## 1. Register a GitHub OAuth app

In GitHub, go to **Settings → Developer settings → OAuth Apps → New OAuth App**. Set the **Authorization callback URL** to `http://localhost:3000/auth/callback/github` (use your real host in production). GitHub gives you a **Client ID** and a **Client Secret**.

## 2. Configure the server

Users and sessions are kept in memory during development, so there's nothing to configure yet. Put the credentials in the environment:

```bash
GITHUB_ID=your-client-id
GITHUB_SECRET=your-client-secret
SECRET=a-long-random-string   # signs the session cookie
```

```js
import server from '@server/next';

export default server({ auth: 'cookie:github' })
  .get('/', (ctx) =>
    ctx.user
      ? `Hi ${ctx.user.name}`
      : '<a href="/auth/login/github">Sign in with GitHub</a>',
  );
```

In development the users and sessions live in memory. For production, back them with something persistent like Redis (see [`sessions`](/documentation/options#optionssessions)):

```js
import server, { kv } from '@server/next';
import { createClient } from 'redis';

const redis = kv(createClient({ url: process.env.REDIS_URL }));

export default server({
  sessions: redis.prefix('session:'),
  auth: { strategy: 'cookie', providers: ['github'], users: redis.prefix('users:') },
});
```

Open the page and click the link: the OAuth flow runs and you come back signed in.

## 3. Protect a route

The signed-in user is on [`ctx.user`](/documentation/context#ctxuser) on every request (`undefined` when logged out), so a one-line middleware guards a route:

```js
const requireUser = (ctx) => {
  if (!ctx.user) return 401;
};

export default server({ auth: 'cookie:github' })
  .get('/account', requireUser, (ctx) => `Your email: ${ctx.user.email}`);
```

## 4. Log out

`POST /auth/logout` clears the session:

```html
<form method="POST" action="/auth/logout">
  <button>Log out</button>
</form>
```
